# Site Pessoal / Portfólio — CP4 (versão final)

Projeto individual de Desenvolvimento Front-End para Web (2026-2), de Herlon Verissimo.

**Páginas:** index, currículo, formulário (contato), multimídia e gráficos.

**Feature em JavaScript:** lista de metas de estudo e tema claro/escuro, ambos salvos no `localStorage` (continuam depois do F5). O formulário de contato valida os campos e guarda as mensagens no navegador.

**Bootstrap 5.3 (via CDN):** `row`, `col-md-6`, `d-flex`, `flex-column`, `flex-sm-row`, `gap-2`, `form-control`, `form-select`, `form-label`, `mb-3` e `visually-hidden`.

**Acessibilidade:** link "Pular para o conteúdo", foco visível, navegação por teclado, rótulos em todos os campos, `alt` na imagem, contraste conferido nos dois temas e gráfico com tabela equivalente.
